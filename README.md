# Video3MB

1080×1440 marketplace videolarini tayyorlash uchun Next.js ilova.

Funksiyalar:
- video yuklash
- bosh/oxirini qirqish
- 3:4 crop yoki fit
- 1080×1440 eksport
- ovozli / ovozsiz
- ovoz balandligi
- matnli watermark
- MP4/H.264
- 3 MB limitga yaqin avtomatik siqish

Video FFmpeg WebAssembly orqali foydalanuvchining brauzerida qayta ishlanadi.

## Ishga tushirish
```bash
npm install
npm run dev
```

## Deploy
Vercel Next.js loyihasi sifatida deploy qilinadi.
